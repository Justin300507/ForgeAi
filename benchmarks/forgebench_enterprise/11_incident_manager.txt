An IT incident management system with user login. Incidents are created with title, description, severity (P1–P4), and affected service. P1 incidents auto-escalate to the on-call manager if unacknowledged after 5 minutes. Each incident has a timeline of status updates (investigating/identified/resolving/resolved). A post-incident review is required before a P1 or P2 can be fully closed. The dashboard shows MTTD and MTTR per severity level.
