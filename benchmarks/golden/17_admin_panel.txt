A multi-tenant SaaS admin panel with two roles: superadmin and user. Superadmin sees all users: email, signup date, plan, last active, banned status. Superadmin can ban/unban users, change their plan, and delete accounts. Users see their own profile and can edit display name and timezone. Audit log tracks all admin actions (who did what and when). Superadmin can export the user list as CSV. Paginated user table with search by email.
